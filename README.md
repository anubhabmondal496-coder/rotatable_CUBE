🚀 Built an Interactive Gesture-Controlled 3D Cube using Python, OpenCV & MediaPipe!

Excited to share one of my recent Computer Vision projects where I created a real-time hand gesture interaction system that allows users to create, move, and interact with a virtual 3D cube using only hand movements.

🔹 Features:
✅ Real-time hand tracking using MediaPipe
✅ Dynamic hand landmark visualization
✅ Gesture-based cube creation using pinch detection
✅ Static cube persistence after gesture completion
✅ Drag-and-move interaction with hand gestures
✅ “Slap to Rotate” mechanism using motion velocity detection
✅ Dynamic visual effects with adaptive colors
